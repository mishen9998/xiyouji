# 卡牌与宝物插画、介绍更新验收

日期：2026-09-17。范围：卡牌与宝物美术及展示文案，不改变游戏规则、封面、角色选择立绘、3D 战斗表现、点击出牌和战败返回菜单流程。主助手顺序开发与自检，未启用子智能体；不作为独立验收。

## 交付

- 86 张卡牌、34 件独立宝物各生成一张新插画，共 120 张，无重复源图。旧名称“降魔宝杖”沿用“降妖宝杖”的图文。
- 使用 imagegen 技能的 built-in image_gen 模式逐张生成。依据原版封面与五名角色参考图，统一为宣纸、墨山、鎏金、朱红与青绿的国风手绘；各角色、动作和器物独立设计。
- [完整提示词、参考图和输出位置](../artwork-v2-prompts.json)；[卡牌源图](../../assets/images/artwork-v2/cards/)；[宝物源图](../../assets/images/artwork-v2/relics/)。原版图片未删除、未覆盖。
- 120 条“西行逸闻”与服务端“实战效果”分开显示。介绍为改编文案，不替代规则，不更改伤害、格挡、费用或奖励。
- 牌组、单人和多人奖励、篝火选牌、商店详情、御赐宝物、宝箱和宝物查看统一接入新图。战斗手牌保留紧凑效果展示和一次点击出牌，逸闻只作为桌面提示。
- 实机页面自检发现玩家牌组摘要遗漏 description；已在 PlayerSummaryAssembler 中补传实际存档描述，保持原字段及路径。旧数据没有描述时仍允许省略，不伪造效果。无数据库迁移或存档重置。
- 手机商店详情调整为 3:2 插画比例，修复浅底卡名对比不足。牌组采用宣纸卡框，宝物详情完整展示器物。
