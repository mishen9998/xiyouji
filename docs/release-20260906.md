## 复现入口

```powershell
npm run test:unit --prefix frontend-vue
npm run build --prefix frontend-vue
.\mvnw.cmd -B -pl xiyouji-bootstrap -am verify
```

双实例测试按 README 的 Compose E2E 流程运行。必须先等待应用健康；重建应用后重建或重启 Nginx，再执行黑盒测试。

本机运行使用隔离项目 `xiyouji-release-check`，Nginx 端口 18080、直连端口 18081/18082，另将应用 CORS 加入 `http://localhost:18080`。浏览器命令：

```powershell
$env:PLAYWRIGHT_BASE_URL='http://localhost:18080'
npm run test:e2e --prefix frontend-vue -- --workers=1
```

恢复演练源项目为 `xiyouji-backup-source`，成功目标为 `xiyouji-restore-18f9ba5f`，本机备份为 `backups/drill-a007586a`。备份文件被 Git/Docker 忽略；它们不是异机灾备。操作详见 [备份恢复说明](backup-restore.md)。
