# 入口修复与原版视觉恢复（2026-09-17）

## 范围

用户要求直接修复“开始西行失败”，恢复先前的沉浸式角色选择与封面；本次未启动多智能体流水线、未更新云服务器、未推送远程。视觉参照 Git 历史 `89fa9fe`，保留当前游戏逻辑、压缩图片、键盘操作和响应式支持。本次不表示此前整套玩法升级或旧多人最终验收阻塞已解决。

## 原因与改动

- 生产安全配置未公开 `/illustrations/**`；压缩图真实 GET 返回 403，页面因此显示占位符。补齐静态资源及 `/menu`、`/complete` SPA 入口白名单，游戏 API 仍需认证。
- 无效 JWT 被默认入口返回 403，而前端只处理 401。现改为明确的 JSON 401，前端提示重新认证；真正的成员权限 403 不会退出有效身份。
- 新增只读 `/api/auth/session`，即使 `/api/auth/**` 公共前缀存在，它也单独要求有效认证。继续登录或复用记住的游客前先检查，不在游戏命令失败时静默创建新游客，不自动重放写请求。
- 迟到的旧身份 401 不会清除后续登录的身份；网络或 5xx 不能触发游客替换。无效凭据会清理，但不删除存档记录或数据库数据。过期游客是否仍能恢复原存档不在本次保证范围内。
- 恢复原版 `login_screen.jpg` 的登录页和主菜单封面、深色金色入口配色、五名角色原插画、选中后的全屏立绘与底部选角卡片。样式限定在入口页，不回滚其他玩法页面。
- 修复手机横屏时底部卡片越界；保留 44/48 像素触控、键盘焦点和减少动画支持。
- Docker Maven 编译使用独立 BuildKit 缓存。首次填充本机测得 Maven 约 3 分 20 秒；随后修改页面的两次构建约 10.6 / 11.1 秒。这是 Maven 阶段，不是总启动时间，也非性能 SLA。

## 使用

打开 `http://localhost:8080/`。如果显示登录失效，请重新登录或主动选择游客模式后开局。无需清空浏览器存储或数据库。

未修改代码时，可以使用 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\demo.ps1 up -NoBuild` 复用本机镜像；代码更新后应重新构建。
