# 游戏美术资源

`images/` 是游戏插图的唯一源目录，按角色、敌人和宝物分类。Vite 开发服务器和 Maven 打包都读取这里，浏览器访问地址保持 `/images/...`。

图片名称到路径的映射由 `frontend-vue/src/constants/images.ts` 维护；对应测试检查全部动态映射是否存在。页面背景由 Vue 样式直接引用。

孙悟空、猪八戒、沙僧的头像与立绘原本是完全相同的 JPEG，现在共用 `建模/full_*.jpg`。白龙马的透明头像和唐三藏的独立头像继续保留。

角色目录中少量未直接加载的原始 PNG 是已有建模/外观参考，保留供后续美术修改使用。生成素材的历史记录见 [生成式插图替换记录](../docs/generated-artwork.md)。
